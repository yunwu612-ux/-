# 《末世包租公》V1.3

V1.3 将游戏从单纯的“修房收租”升级为末世社区经营 + 生存冒险：

- 主线剧情：被家人赶出家门后，在末世安全区开启包租人生
- 房间修复、招租、租金与社区声望
- 物资：废土币、电力、水、食物、药品、建材
- 租客职业与能力：守卫、医生、拾荒者、工程师、厨师、商人、农夫
- 外出搜集：派租客去废墟、超市、医院、仓库搜集资源
- 随机事件：尸潮、补给车、停电、伤病、流浪者、交易商
- 社区设施：发电机、水塔、诊所、围墙、仓库
- 章节式主线目标与每日事件
- 自动存档
- Debug / Release 均使用同一测试签名，便于后续更新安装

本作使用原创角色、地点和数值设计，仅采用“末世+包租经营”这一类型化玩法方向，不复制原作品正文。


V1.3 修正版：签名文件已放置在 app/release.keystore，GitHub Actions 使用 Gradle 8.9；从 V1.2 升级时会自动迁移基础存档。
