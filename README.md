# 末世包租公 V1.1

Android 2D 末世社区经营小游戏。

## V1.1 更新
- 加入自动存档：退出/切后台后再次打开会恢复天数、资金、资源、系统等级、已建房间与租客。
- 优化 Compose 列表：为房间和租客列表加入稳定 key/contentType，减少滚动与状态更新时的无效重组。
- 候选租客数据只创建一次，减少重复对象分配。
- 房间操作改为按稳定 ID 定位，避免列表项变化时依赖对象比较。
- 使用 `rememberSaveable` 保存界面关键状态，旋转/重建时恢复更平滑。
- 保持 V1.0 核心玩法不变。

## 构建
使用 Android Studio 或 GitHub Actions 构建 Debug APK。
